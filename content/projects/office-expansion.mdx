## The problem

The practice needed more workspace. IT's part of that is rarely the visible part: it is the cabling schedule, the port count, the switching capacity and the assurance that every desk actually works on the first morning.

The constraint was the same one that shapes most of this environment — no dedicated project team, and no contractor for the physical work. The cabling, termination, patching, switch configuration and testing were all done in-house, alongside day-to-day support.

## Constraints

- **No dedicated project team.** The expansion had to be delivered alongside normal support work, not by a separate builds team.
- **A live floor.** The existing workspace could not be interrupted during working hours, so the build had to be sequenced around it.
- **Everything ran through one pair of hands.** There was no contractor for the cabling or containment, so the physical build, patching, configuration and testing all had to fit around support work.
- **The physical build had to match the network.** Port allocation, patch panel layout and labelling had to agree with the documented scheme, or the next change would start from a guess.

## Architecture

The design started as a **port schedule rather than a cable order**: how many desks, where, how many devices per desk, and what the patch panel and switch would need to look like to keep changes sane later.

That schedule set the rest of the build:

- **Structured cabling** from the patch panel to each workspace outlet.
- **Patch panel and switch port allocation** sized to the desk plan, not the other way round.
- **A labelling scheme** matching the existing floor, so a port can be traced from the panel to the desk.
- **A written handover record** tying each workspace to the port that serves it.

## Implementation approach

From the port schedule I ran the structured cabling, terminated and dressed the patch panel, allocated and labelled the switch ports, configured the switching, and tested each workspace before handover. Doing the physical build and the network configuration together kept the port scheme, labelling and switch allocation consistent with the existing floor.

The work was scheduled to keep the existing floor running: no shared uplink was taken down during working hours, and each run was completed around occupied desks rather than shutting the floor down.
